# Bank Marketing Data Analysis with Python

## Project Overview

This project analyzes a bank marketing dataset to understand the customer and campaign characteristics associated with successful term deposit subscriptions.

The analysis was completed in Python and focuses on data cleaning, exploratory data analysis, feature engineering, visualization, and business-focused analysis.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed

- Initial data inspection
- Data quality assessment
- Duplicate detection
- Outlier analysis
- Data type review
- Customer filtering
- Feature engineering
- Grouped analysis
- Data visualization
- Business analysis

## Business Questions

The analysis investigates questions such as:

- Which customer job groups have the highest deposit success rates?
- Which age groups have the highest deposit rates?
- How do housing and personal loans relate to deposit success?
- Which education groups perform best?
- Which months produce the most successful deposits?
- How does customer balance differ between successful and unsuccessful deposits?
- How does previous campaign performance relate to current outcomes?
- How does campaign contact frequency relate to deposit success?
